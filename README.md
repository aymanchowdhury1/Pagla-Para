# Para'r Pagla — Desi Chaos (Flat Folder Prototype)

All project files are in the same folder:
- `index.html`
- `style.css`
- `game.js`

## Run
Open the folder in VS Code and use the Live Server extension on `index.html`.
This project uses JavaScript modules and must be served over HTTP; don't double-click the HTML file.

## Controls
- PC: WASD / arrow keys move, Shift runs, E interacts.
- Drag mouse to rotate camera.
- Phone: use on-screen directional controls and DO IT!.

## Hosting
Upload all three files to the root of a separate GitHub repository, then enable GitHub Pages from `main` / root.

Three.js is loaded from jsDelivr with an unpkg fallback, so internet access is required.
